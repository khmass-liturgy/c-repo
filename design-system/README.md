따뜻한 등 하나가 켜진 어두운 연습실입니다. 이 제품은 한 페이지짜리 클래식 기타 연습실로, 레퍼토리 목록, 타이머·메트로놈·조율기가 있는 오늘의 연습, 연주회 준비, 악보 자료실, 공연 이력으로 이루어져 있습니다. 새 화면도 같은 방 안에 있는 것처럼 만드세요.

## 말투와 문구

- 화면 문구는 한국어로, `-습니다` 또는 `-해주세요`로 끝나는 정중한 평서문으로 씁니다. 실제 예: "삭제되었습니다", "순서가 변경되었습니다", "날짜를 먼저 선택해주세요", "같은 이름의 곡이 이미 있습니다".
- 일어난 일을 짧은 한 문장으로 알립니다. 오류는 다음에 할 일을 말합니다: "악보 파일은 20MB 이하만 올릴 수 있습니다".
- 영어는 제목 위의 작은 대문자 라벨에만 씁니다: "Classical Guitar Practice Studio", "Professional practice, made personal". 컨트롤에는 쓰지 않습니다.
- 큰 문구는 짧은 두 줄로 쓰고, 요점인 둘째 줄을 `gold2`로 둡니다: "많이 치는 연습보다 / 정확히 남는 연습".
- 곡의 네 가지 상태는 정해진 낱말입니다: 암보, 연습중, 완성, 공연가능. 번역하거나 바꾸지 않습니다.
- 빈 상태는 담백한 한 문장입니다: "검색 결과가 없습니다", "공연 이력이 없습니다."
- 느낌표를 쓰지 않습니다. 이모지는 사용자가 고른 카테고리 아이콘에만 나오며 문구 장식으로 쓰지 않습니다.

## 색

- 화면에 보이는 제품은 Studio입니다. Paper는 원래의 밝은 팔레트로, 밝은 환경과 인쇄의 바탕으로 남겨 두었습니다. Studio를 먼저 설계하세요.
- 바탕은 어두운 것에서 밝은 것 순으로 쌓습니다: body는 `page`, 입력하거나 켜고 끄는 것은 `well`, 패널은 `raised`와 `bg2`, 선택된 탭과 토스트는 `active`.
- 본문 글자는 어느 바탕에서나 `cream`입니다. 곡·카테고리·단계의 제목은 `heading`, 보조 글자와 비활성 컨트롤은 `muted`입니다.
- 강조색은 `gold` 하나뿐입니다. 아이브로, 활성 필터, 외곽선 버튼, 세리프 숫자에 씁니다. hover와 활성 글자, 실시간 수치에는 `gold2`를 씁니다.
- `gold`로 꽉 채운 면은 도구마다 하나뿐인 주 동작(타이머 시작, 메트로놈 실행 중)에만 씁니다. 그 위 글자는 `cream`이 아니라 `on-gold`입니다.
- 새 투명도 값을 만들지 말고 `gold-wash`로 물들이고 `gold-line`으로 선을 긋습니다.
- 상태색은 각각 한 가지 뜻만 가집니다: `red` 암보, `orange` 연습중, `green` 완성, `gold` 공연가능. 상태는 언제나 낱말도 함께 보여 주므로 색에만 의존하지 않습니다.
- `info`는 계정과 파일 동작(계정 동기화, 악보 열기)에만 씁니다.
- 원본 그대로 둔 대비 주의점: `border`는 두 테마 모두 바탕 대비 3:1에 못 미치므로 가는 선 하나만으로 상태를 알리지 마세요. Paper에서 `gold`와 `orange` 글자는 흰 바탕에서 4.5:1 언저리이고 `bg` 위에서는 그보다 낮으니 `page` 위에만 둡니다.

## 글자

- 서체는 둘입니다. `serif`(Noto Serif KR)는 제목, 기울인 곡명과 작곡가 이름, 모든 큰 숫자에 씁니다. `sans`(Noto Sans KR)는 읽거나 누르는 모든 것에 씁니다.
- `t-h1`은 페이지에 하나만 씁니다. 화면 제목은 `t-section`, 패널은 `t-panel`, 카테고리는 `t-category`입니다.
- 시계, BPM, 개수는 세리프에 `font-variant-numeric: tabular-nums`를 줍니다(`t-timer`, `t-readout`, `t-note`).
- 대문자 라벨은 언제나 작고 자간이 넓습니다: `t-header-label`, `t-eyebrow`, `t-kicker`, `t-form-label`. 제목 위는 금색, 입력란 위는 `muted`입니다.
- 작곡가 이름은 제목 옆에 기울인 세리프로 `composer` 색을 씁니다.
- 두 서체 모두 Google Fonts에서 굵기 400~700으로 불러옵니다. 시스템 안에 글꼴 파일은 없습니다.

## 모양, 간격, 깊이

- 모서리 반경은 대상이 클수록 커집니다: 컨트롤 `radius-8`, 알약 `radius-9`, 카드와 섹션 `radius-10`, 탭 바 `radius-12`, 패널 `radius-14`, 히어로 `radius-18`. 상태 배지는 `radius-2`로 날카롭게 둡니다.
- Paper는 모든 컨트롤에 `radius-2`를 씁니다. 반경 토큰은 테마에 따라 바뀌지 않으므로 Paper용으로 만들 때는 직접 지정하세요.
- 그림자가 아니라 1px `border` 선과 바탕 한 단계 차이로 구분합니다. 그림자는 떠 있는 것에만 씁니다: `shadow-modal`, `shadow-popup`, `shadow-toast`.
- 간격은 격자가 아니라 원본이 실제로 쓰는 값입니다: 버튼 사이 `space-8`, 패널 사이와 행 여백 `space-18`, 히어로 안쪽 `space-30`.
- 앱 본문 폭은 1120px이고 좌우 여백은 `space-20`입니다. 연습 화면은 1.55 대 0.75의 두 칸 격자이며 820px 아래에서 한 칸으로 쌓입니다.
- 움직임은 짧고 조용합니다: 0.15~0.2초의 색·테두리 전환, 타이머 버튼 hover 때 1px 올라감. 튀는 효과는 없습니다.
- 페이지 바탕에는 아주 옅은 방사형 빛이 둘 있습니다(왼쪽 위 금색, 오른쪽 녹색). 히어로에는 5% 금색의 큰 높은음자리표 글리프가 하나 더 있습니다. 그 밖의 이미지는 쓰지 않습니다.

## 아이콘

- 아이콘 세트는 없습니다. 컨트롤은 글자 글리프(＋, ×, ▲, ▼, ✓)를 쓰고, 카테고리 아이콘은 사용자가 고르는 이모지입니다.
- 앱 아이콘은 거의 검은 바탕의 금색 고리 안에서 기타를 연주하는 천사 그림입니다. Icons 자산 그룹에 있습니다. 앱 아이콘으로만 쓰고 화면 안에는 넣지 않습니다.

## 컴포넌트

- 컴포넌트 스타일은 `components/bundle.css`에 있으며 원본의 클래스 이름(`.hdr-btn`, `.tab-btn`, `.status-badge`, `.piece-item`)을 그대로 씁니다. 스크립트 번들은 없고 미리보기는 정적 마크업입니다.
- 키보드 포커스는 2px `gold` 외곽선으로 표시합니다. 의도적으로 추가한 것이며, 원본은 외곽선을 없애고 포커스 스타일이 없습니다.

## 가져오지 않은 것

- 인쇄 스타일(A4 용지, pt 크기, `--print-dot`)은 뺐습니다.
- 유동 크기 `clamp(34px, 6vw, 54px)`와 `clamp(28px, 4vw, 43px)`는 최댓값으로 기록했습니다.
- `favicon.ico`는 복사하지 않았고 PNG 크기들만 가져왔습니다.
- 원본에서는 직접 쓴 값이고 여기서 이름을 붙인 것: `page`, `well`, `raised`, `item`, `active`, `track`, `border-strong`, `heading`, `composer`, `info`, `on-gold`, `gold-line`, `gold-wash`, `needle-off`, `needle-on`. `active`, `track`, `item`의 Paper 값은 원본에 직접 대응하는 값이 없습니다.
- 간격과 반경은 원본에서 변수가 아닙니다. 토큰은 가장 많이 쓰인 값에 이름을 붙인 것입니다.
- 컴포넌트 27개는 모두 `index.html`을 읽고 정적 CSS로 손으로 옮긴 것입니다. 원본의 화면 컴포넌트 계열은 모두 포함했고, 인쇄 레이아웃, 악보 불러오는 중 화면, KHCG 선택 모드는 포함하지 않았습니다.
- 원본의 직접 쓴 값 대신 토큰으로 그린 것: 페이지 제목 색, 연습 히어로 배경, 곡 모달의 작곡가 입력란.
- 테두리에 가까운 원본 값 둘(조율기의 #343b40, 악보 자료실 행의 #30373d)은 `border`로 그렸습니다.
