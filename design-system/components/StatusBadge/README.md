곡의 준비 정도를 정해진 네 낱말 중 하나로, 각자의 색과 함께 보여 줍니다.

`index.html`에서 손으로 옮긴 정적 CSS 클래스입니다. 상태 낱말을 클래스 접미사와 라벨 양쪽에 넣습니다: `status-badge status-완성`.

| 상태 | 색 | 뜻 |
| --- | --- | --- |
| 암보 | `red` | 외우는 중. |
| 연습중 | `orange` | 연습하는 중. |
| 완성 | `green` | 다 익힘. |
| 공연가능 | `gold` | 무대에 올릴 수 있음. |

- 레퍼토리 목록에서 배지는 버튼입니다. 누르면 다음 상태로 넘어갑니다.
- 낱말을 항상 보여 주세요. 원본의 색 기운과 테두리는 투명도가 낮아 색은 보조 신호일 뿐입니다.
- `last-played`는 마지막 연주 뒤 지난 시간입니다. 오래될수록 `warning`, `danger`를 붙입니다.
