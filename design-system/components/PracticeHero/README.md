연습 화면을 여는 카드입니다. 아이브로, 두 줄 세리프 문구, 문단, 그리고 오늘의 시간과 목표를 고르는 도구 모음으로 이루어집니다.

`index.html`에서 손으로 옮긴 정적 CSS 클래스입니다. 아이브로, 둘째 줄을 `<span>`에 넣은 문구, 문단, 컨트롤, 요약을 넣습니다.

- 문구는 `t-hero`이며 span은 `gold2`가 됩니다. 짧은 두 줄로 유지합니다.
- 오른쪽 위 모서리에 옅고 큰 높은음자리표가 있습니다. `::after`로 넣은 장식이며 다른 것은 더하지 않습니다.
- `practice-toolbar`에는 `practice-control` 묶음(작은 `muted` 라벨 아래 `duration-pills` 또는 `goal-select`)과 오른쪽 정렬된 `practice-summary`(세리프 `gold2` 숫자)가 들어갑니다.
- 히어로는 화면마다 맨 위에 하나만 씁니다. `radius-18`과 금색 외곽선을 가진 유일한 면입니다.
- 배경은 `bg2` 위로 옅어지는 `gold-wash`입니다. 원본은 조금 더 진한 금색(11%)을 두 단계 어두운 그러데이션 위에 씁니다.
