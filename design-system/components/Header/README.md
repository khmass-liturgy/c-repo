페이지 헤더입니다. 대문자 영문 라벨, 금색 기울임 낱말 하나가 든 세리프 제목, 보조 버튼, 레퍼토리 통계 줄로 이루어집니다.

`index.html`에서 손으로 옮긴 정적 CSS 클래스입니다. 제목, 동작 버튼, 통계 최대 여섯 개(숫자와 라벨)를 넣습니다. 원본에서는 감싸는 요소가 클래스 없는 `<header>`이고, 여기서는 `app-header` 클래스를 붙였습니다.

- 제목은 페이지에 하나뿐인 `t-h1`입니다. 핵심 낱말을 `<em>`에 넣으면 기울인 `gold`가 됩니다.
- `header-actions`에는 Button 변형이 들어갑니다: 보조 버튼, 계정 동기화 버튼, 인쇄.
- 동기화 버튼 안에는 `sync-dot`이 있습니다. 로그아웃 상태는 회색, `synced`는 초록, `syncing`은 깜박이는 `amber`, `error`는 빨강입니다. 로그인하면 버튼에 `connected`를 붙입니다. 점에는 항상 글자 라벨을 함께 둡니다.
- `header-stats` > `stat`: 세리프 `gold` 숫자와 그 아래 대문자 `muted` 라벨. 앱의 여섯 항목은 Total, 전체시간, 공연가능, 공연가능 시간, 연습중, 공연이력입니다.
- `sync-status-text`는 통계 아래의 `muted` 한 줄입니다.
- 원본의 제목 색은 #faf5eb이며 여기서는 `heading`으로 그렸습니다.
