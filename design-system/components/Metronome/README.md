템포 도구입니다. 증감 버튼과 슬라이더가 있는 BPM 표시, 시작 토글, 박자 버튼, 박 점 줄로 이루어집니다.

`index.html`에서 손으로 옮긴 정적 CSS 클래스입니다. BPM, 마디당 박 수, 켜진 점을 넣습니다. 소리는 페이지의 스크립트가 냅니다.

- 수치는 고정폭 세리프 `gold2`이고 단위는 `t-micro`입니다.
- `metro-toggle`은 실행 중(`active`)일 때 `gold`로 채워지고 글자는 `on-gold`입니다.
- 박마다 `metro-dot` 하나입니다. 첫 박에 `accent`, 현재 박에 `active`가 붙고 `shadow-glow`로 빛납니다.
- 앱에서는 메트로놈이 타이머 패널 안에 위쪽 테두리만 두고 들어가며 따로 외곽선이 없습니다. 이 미리보기의 외곽선은 단독으로 쓸 때를 위한 것입니다.
