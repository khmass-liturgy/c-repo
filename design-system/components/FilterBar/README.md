레퍼토리 화면의 맨 위입니다. 짧은 개요 카드, 상태 필터, 곡 추가 버튼, 검색으로 이루어집니다.

`index.html`에서 손으로 옮긴 정적 CSS 클래스입니다. 필터 라벨과 활성 필터, 검색 입력란을 넣습니다.

- `repertory-overview`는 세리프 제목과 도움말 한 문장이 있는 조용한 `bg2` 카드입니다.
- `controls`는 좁은 화면에서 줄바꿈됩니다. 검색창은 오른쪽으로 밀리고 600px 아래에서 전체 폭이 됩니다.
- `filter-btn`은 외곽선 토글입니다. 선택된 것에 `active`를 붙입니다(금색 테두리, 금색 글자, 옅은 금색 채움). 필터는 네 상태와 '전체'입니다.
- `btn-add-piece`는 곡을 추가하는 금색 외곽선 동작입니다. `btn-add`는 모달 안에서 쓰는 각진 모서리 짝입니다.
