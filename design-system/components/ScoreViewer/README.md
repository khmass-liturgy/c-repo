악보 파일을 보는 검은 전체 화면 뷰어입니다. 위쪽 바에 닫기, 파일 이름, 전체 화면 버튼이 있습니다.

`index.html`에서 손으로 옮긴 정적 CSS 클래스입니다. 파일 이름과, `score-viewer-stage` 안에 이미지나 PDF로 된 악보를 넣습니다. 이 미리보기의 흰 종이는 자리 표시입니다.

- 뷰어는 일부러 팔레트 밖에 있습니다. 두 테마 모두 중립 검정과 흰 글자를 써서 악보만 밝게 보이게 합니다.
- `open`을 붙이면 보입니다. 창 전체를 덮고 앱에서는 safe-area 여백을 지킵니다.
- `score-viewer-button`의 누르는 영역은 최소 42px, 700px 아래에서는 46px입니다.
- 닫기는 언제나 맨 왼쪽 위의 첫 컨트롤입니다.
