공연 이력입니다. 날짜마다 한 행으로 장소와 연주한 곡을 보여 줍니다.

`index.html`에서 손으로 옮긴 정적 CSS 클래스입니다. 공연마다 날짜, 요일, 장소, 곡 제목을 최신순으로 넣습니다.

- `tl-date`는 세리프 `gold`이고 그 아래 요일은 `muted`입니다.
- 곡 제목은 `border` 외곽선과 `radius-2`의 기울인 세리프 칩(`tl-piece`)입니다.
- 행은 `border` 선으로 구분하며 카드를 쓰지 않습니다.
- 이력이 없으면 `empty-state`를 보여 줍니다: "공연 이력이 없습니다."
