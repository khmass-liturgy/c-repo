연습한 지 오래된 곡의 목록이며 타이머 패널 맨 아래에 나옵니다.

`index.html`에서 손으로 옮긴 정적 CSS 클래스입니다. 머리말과, 곡마다 제목 그리고 마지막 연주 뒤 지난 날수와 목표 간격이 든 정보 줄을 넣습니다.

- `practice-panel` 안의 섹션으로 둡니다. 다른 섹션 뒤에 오면 위쪽 테두리가 생깁니다.
- `rotation-head`는 ↻ 글리프와 "오래 쉬었던 곡"입니다.
- 각 `rotation-row`에는 넘치면 잘리는 굵은 제목과 "41일 전 · 14일마다 목표" 같은 `muted` 정보 줄이 있습니다. 한 번도 연주하지 않은 곡은 "기록없음", 오늘은 "오늘"이라고 씁니다.
- 몇 행만 보여 주고 나머지는 `rotation-more` 줄로 알립니다.
