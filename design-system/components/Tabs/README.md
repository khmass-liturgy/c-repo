탭은 두 단계입니다. 다섯 개 주 화면을 위한 분할 바와, 레퍼토리 카테고리를 위한 밑줄 바입니다.

`index.html`에서 손으로 옮긴 정적 CSS 클래스입니다. 버튼을 넣고 선택된 것에 `active`를 붙입니다.

- `tab-bar` > `tab-btn`: 주 화면이며 순서는 레퍼토리 관리, 오늘의 연습, 연주회 준비, 악보 자료실, 공연 이력입니다. 선택된 탭은 `active` 바탕에 `shadow-ring`과 `gold2` 글자입니다. 좁은 화면에서는 바가 옆으로 스크롤됩니다.
- `cat-tab-bar` > `cat-tab`: 레퍼토리 화면 안의 카테고리입니다. 각 탭에 `tab-icon`(사용자의 이모지), 이름, `tab-count` 칩을 넣을 수 있습니다. 선택된 탭은 `gold` 글자에 2px `gold` 밑줄입니다.
- 분할 바는 페이지에 한 번만 씁니다. 화면 안에 분할 바를 또 넣지 않습니다.
