여섯 개방현을 위한 마이크 조율기입니다. 음 이름, 바늘이 있는 편차 미터, 줄 선택 줄로 이루어집니다.

`index.html`에서 손으로 옮긴 정적 CSS 클래스입니다. 감지된 음과 주파수, 바늘 위치(`left` 퍼센트, 50%가 정확), 활성 줄을 넣습니다.

- `practice-panel` 안의 섹션으로 둡니다. 다른 섹션 뒤에 오면 위쪽 테두리가 생깁니다.
- `tuner-note`는 세리프 `gold2`이고 `tuner-frequency`는 고정폭 숫자입니다.
- 바늘은 허용 범위에 들기 전까지 `needle-off` 빨강이고, 들어오면 `in-tune`을 붙여 `needle-on` 초록이 됩니다. 중앙선은 `green`입니다. 눈금에 낮음, 정확, 높음이라는 낱말이 있어 색만으로 알리지 않습니다.
- `tuner-strings`는 언제나 E2, A2, D3, G3, B3, E4와 줄 번호를 보여 주며 가장 가까운 줄에 `active`를 붙입니다.
- 여기 테두리는 `border`를 씁니다. 원본은 한 단계 밝은 값(#343b40)을 직접 씁니다.
